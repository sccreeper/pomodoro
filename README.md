# QT Pomodoro Timer

A pomodoro timer app I made to learn C++ basics and Qt. See a writeup on my blog.

## Features (checklist)
 
- [ ] Counting down/pausing starting
- [ ] Doing breaks/intervals
- [ ] Updating button text
- [ ] Updating status bar in UI
- [ ] Desktop notifications for status
- [ ] Saving user preferences

## Requirements

- C++ 20 
- CMake
- Qt6 or higher
- VCPKG

Below are lists of packages for various Linux distributions.

### Required packages (Fedora)

```
sudo dnf install cmake gcc-c++ qt6-qtbase-devel qt6-qtwayland-devel
```
